ANCHOR PWA — FILES TO UPLOAD TOGETHER

Upload the CONTENTS of this folder to the root of one GitHub repository:
- index.html
- manifest.webmanifest
- sw.js
- icons/ folder (keep all three PNG files inside it)

Do not upload only index.html. The manifest, service worker, and icons are what make the hosted site installable as a PWA.

Your bill entries are stored in the browser on your device. They are NOT placed in the GitHub repository.
Use the Backup button periodically because clearing Safari website data/removing site data can remove local app data.
